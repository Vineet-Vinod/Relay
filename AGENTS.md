# Relay - AGENTS.md

Relay is a pre-release application with zero users.
Hence, do not feel obligated to always implement the "smallest possible" or "least breaking" change.
Implement the change that will leave the app in the most maintainable, extensible, and best functioning state.

Please keep security best practices in mind while implementing this application.

For UI work, consult `docs/ui-ux-ruleset.md` before implementing or revising any user-facing surface.
Prefer evolving the app toward that shared ruleset instead of introducing one-off styling decisions.
